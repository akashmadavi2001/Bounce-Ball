# Bounce-Ball

Bounce Ball is a fun and interactive browser-based game designed to provide an enjoyable gaming experience with simple and engaging gameplay.

## Live Demo
[Play Bounce Ball](https://akashmadavi2001.github.io/Bounce-Ball/)

## Features
- Interactive browser-based gameplay
- Simple and user-friendly interface
- Smooth and engaging game experience
- No installation required
- Play directly in your web browser

## Technologies Used
- HTML
- CSS
- JavaScript

## Objective
Enjoy a simple, fun, and interactive bouncing ball game directly in your browser.

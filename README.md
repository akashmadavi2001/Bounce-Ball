# Bounce-Ball

The Marquee Effect with Ball Bounce is a frontend animation project created using HTML and CSS. In this project, a ball moves continuously across the screen, creating a bouncing effect while moving from one side to the other.
HTML is used to create the structure of the webpage, including the ball and its container. CSS is used to style the ball and apply animations using @keyframes, transform, and positioning properties.
The ball moves horizontally like a marquee and bounces vertically to create a realistic movement effect. This project helps beginners understand CSS animations, keyframes, transforms, positioning, and timing functions.
